# 06｜课程时间线与方法展开

## 说明

课程语料不足以构建薛睿个人生平时间线。本文件记录两套课的可验证方法进阶。

| 分集 | 阶段 | 方法上的新增 |
| --- | --- | --- |
| 形式 P01—P03 | 定向 | 考试能力结构、题型边界、考官常见包装 |
| 形式 P04—P20 | 逻辑语言 | 命题、真假、取非、OR、逆否、前真后假与文字还原 |
| 形式 P21—P39 | 范围与真假 | 量词、模态、代入、真假判断和复杂等价 |
| 形式 P40—P55 | 分析启动 | 矛盾、名额、一一对应、真假话、文氏图和直言命题 |
| 形式 P56—P63 | 表格系统 | 队列、分组、分类、多对多和相邻关系 |
| 论证 P01—P14 | 论证入口 | 论据/结论、补全逻辑、引入前提和过强假设 |
| 论证 P15—P24 | 支持系统 | 前假后假、建立联系与常见陷阱 |
| 论证 P25—P50 | 因果系统 | 由果推因、由因推果、比较差异、比例、反事实和第三变量 |
| 论证 P51—P61 | 高阶问法 | 解释、评价、两人对话和结论推出 |
| 论证 P62—P72 | 分析补强 | 队列、标准/复合分组和多对多表格复练 |

## 推荐运行顺序

1. 先完成形式语言和条件方向。
2. 再训练真假、分析启动和表格回填。
3. 然后进入论证结构、假设、支持和因果。
4. 最后用论证课尾部的队列/分组检查迁移。
