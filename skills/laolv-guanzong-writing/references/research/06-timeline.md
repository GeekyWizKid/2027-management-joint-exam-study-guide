# 06｜课程时间线与方法展开

## 说明

课程语料不足以构建老吕个人生平时间线。本文件记录两套写作课的方法展开。

| 分集 | 阶段 | 方法上的新增 |
| --- | --- | --- |
| 7 讲 P01—P08 | 定向 | 试卷任务、评分重点、论效与论说文边界、全年计划 |
| 7 讲 P09—P14 | 论效方法 | 全文稳定结构、得分点、三层漏洞分析 |
| 7 讲 P15—P25 | 论效真题 | 管综与经综材料中的找点、分析和成文 |
| 7 讲 P26—P36 | 论说文方法 | SXOY、材料类型、中心论点、分论点和段落展开 |
| 7 讲 P37—P48 | 论说文真题 | 跨年份、跨考试口径迁移审题和结构 |
| 33 篇 P01—P05 | 论效再建模 | 母题识别和稳定拿分流程 |
| 33 篇 P06—P12 | 论说文再建模 | 无 X、单 X、双 X、带 Y 和关系型材料 |
| 33 篇 P13—P22 | 素材与关系 | 主题素材、关系型通用结构及适用边界 |
| 33 篇 P23—P33 | 预测与限时 | 用新材料检验迁移，不改变真题基准 |

## 推荐运行顺序

1. 先用 7 讲建立评分、审题和段落规则。
2. 完成真题，记录审题和论证失分。
3. 再用 33 篇按材料类型回补并扩充覆盖。
4. 考前只回看具体缺口，不把两套课程完整重复一遍。
