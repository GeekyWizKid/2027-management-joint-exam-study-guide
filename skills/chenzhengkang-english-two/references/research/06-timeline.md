# 06｜课程时间线与方法展开

## 说明

课程语料不足以构建陈正康个人生平时间线。本文件记录《英语二要点 7 讲》的方法展开。

| 分集 | 阶段 | 方法上的新增 |
| --- | --- | --- |
| P01 | 非教学导流 | 保留在索引，但不计入知识进度 |
| P02—P04 | 考试定向 | 大纲、题型、能力要求和学习计划 |
| P05—P08 | 完型 | 词义、搭配、句法和上下文约束 |
| P09—P14 | 阅读 | 六类题型、题干标志、定位、同义改写和干扰项 |
| P15—P17 | 新题型 | 标题、段落功能、指代、连接和整体排序 |
| P18—P21 | 翻译 | 中英思维差异、长句主干、信息重组和校订 |
| P22—P25 | 小作文 | 身份、对象、目的、任务点、语气和真题演练 |
| P26—P29 | 大作文 | 图表核对、趋势、关键数据、评论和真题演练 |

## 推荐运行顺序

1. 先用 P02—P04 做题型和基础诊断。
2. 阅读作为持续主线，完型和新题型强化篇章证据。
3. 翻译用于检验句法和信息重组。
4. 写作先守任务点与准确性，再增加表达多样性。
