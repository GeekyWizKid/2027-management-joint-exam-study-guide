## ③ 阅读笔记

**核心论点**

这节课的核心是：把材料中的推理压缩清楚，再用与漏洞对应的分析动作写成段落。真正需要反复练的是“认”——找到被质疑的具体推断；“套”应当套分析步骤，每次仍要换成题目中的对象、条件和概念。

课堂反复强调的“不一定”，实质是把结论的确定性降回证据所能支持的程度。目标不是证明相反结论必然为真，而是说明**现有论据不足以支持原结论**。

**论证结构**

全课顺序是“论据问题→论证过程问题→论点问题”，每一类再走“识别信号→分析动作→真题例段→回扣结论”。类别并不完全互斥：老师明确说以偏概全可归到论据或推理过程；不当推断是较宽的总类；滑坡放在强制充分条件之下，不能另加成第十一类。

对一段论效分析，可以整理成三步：

1. **定位推断**：准确指出材料用什么论据推出什么结论，给出“不足以推出”的判断。
2. **解释缺口**：结合材料补出其他结果、缺少的条件、替代措施、有关差异或概念含义；至少讲清一个理由。
3. **必要时回扣**：说明这个缺口怎样影响本段或全文结论。字数够、理由已说清时，不必每段都添同一句总结。

**十大谬误：实际课堂清单与下笔动作**

| 课堂类别 | 识别时问什么 | 落笔时做什么 |
|---|---|---|
| 1. 论据不成立 | 这是题目给定的事实，还是缺少根据的断定/尚需检验的理论？ | 指出断定缺乏支持，或说明理论局限与题中适用缺口；不要仅因理论来自某学派就否定它。 |
| 2. 以偏概全 | 从哪些样本、局部情形推到多大范围？样本能代表总体吗？ | 说明样本覆盖或代表性不足，以及未调查部分可能不同。本篇仅回顾，详细说明须补第1篇。 |
| 3. 不当推断 | 论据A为什么就能推出结论B？ | 用其他可能结果、其他/反面因素说明A不足以支持B；必要时展开一个假设情形。 |
| 4. 强制充分条件 | 有A是否真的足以保证B？连续链的每一步都有依据吗？ | 说明A成立而B仍可能不成立；滑坡链至少切断一个关键环节，并解释为何影响最终结论。 |
| 5. 强制必要条件 | 达到P真的非用措施M不可吗？ | 找出一个真正不同、且能实现同一目的P的替代措施。不是随便补“其他因素”。 |
| 6. 归因不当 | 是在解释已经出现的现象吗？原因被证实了吗？是否说成唯一原因？ | 原因未证实时给出合理他因；原因确有贡献时承认部分作用，再指出仍有其他原因。 |
| 7. 不当类比 | 前后对象、时间、地域是否变化？这些变化是否关系到结论？ | 列出与结论有关的差异，解释为什么原经验未必能够迁移。 |
| 8. 偷换/混淆概念 | 前后相似词是否真的同义？同一个字是否换了含义？ | 分别解释两个概念，指出不同，然后说明由前一概念不能直接推出后一概念。 |
| 9. 自相矛盾 | 前后是否在同一条件下肯定又否定同一件事？ | 摆出冲突双方，点明不能同时成立；注意跨段搜寻。 |
| 10. 论点过于绝对 | 结论中的“必然、只有、一定”是否超出了证据支持？ | 说明仍有哪些条件、限制或其他可能，使该断定不够可靠。 |

**可套用表达——以下均为整理改写，不是老师逐字原话**

- 论据审查：“材料将A作为前提，但尚未提供足以支持A的依据。如果存在C，那么A便未必成立，因而也难以据此推出B。”
- 不当推断/充分条件：“即使A成立，也未必能够推出B。B还取决于C；若C未得到满足，那么A出现时，B仍可能不发生。”
- 必要条件：“实现P未必要采用M。M并非唯一途径，通过N也可能实现同一目的，故材料将M视为必需条件的依据不足。”
- 归因不当：“B可能是A出现的原因之一，但不足以据此认定它是唯一原因；C等因素也可能促成A。”
- 不当类比：“A与B在C方面存在与结论有关的差异，因此，A的情形不足以保证B也会得到相同结果。”
- 偷换概念：“材料中的A侧重于……，B则指……，二者含义不同，因此不能由关于A的判断直接推出关于B的结论。”
- 自相矛盾：“材料一方面认为A，另一方面在相同条件下又否认A，两种说法难以同时成立。”

替换字母后仍要再检查：补出的理由是否确实相关，是否真正反驳了材料的推理。只写“不一定”“还有其他因素”而不解释，不算完成分析。

**重点考点**

- **论据—结论和原因—结果要分开。** “因为地湿，所以推测昨夜下雨”是由结果推原因；不能只看到“因为”就套归因题。
- **充分与必要采用不同反驳方向。** 充分：A具备，B仍可能不成立。必要：不用A，仍可能通过别的路径实现B。
- **归因有两种力度。** “可能不是这个原因”与“可能不只是这个原因”不能混用；已有贡献不能随意全部否定。
- **概念辨析是找点训练重点。** 对照前后的主语、谓语和关键词，尤其警惕“实际效用”被换成“真实存在”等同字异义。
- **训练顺序：先认、再写、后核对。** 先看答案再抄一遍，只练到了复现，检验不了独立找点能力。

**易错注意点与使用边界**

1. 课堂为了便于记忆，有“见到条件词就质疑”的简化口语。实际使用时，**条件词只负责定位关系**，仍要证明条件不充分、不必要或缺少支持；不能把有效推理也一律反对。
2. “假设展开”要补足推理，不是单纯凑字。假设须与原材料相容、与结论相关，不能编造已经发生的事实。
3. “不一定B”不等于“一定不B”。对自己提出的可能情形保留“可能、未必、如果”，不要另立一个武断结论。
4. 替代措施必须跳出原措施范围。用报纸替代大众媒体、用“更高价卖出”替代低买高卖，都没有形成真正的新路径。
5. 不当类比不能止于“两个对象不同”；必须补出会影响结果的差异。概念辨析也不能随意解释词义，应依据材料和通常语义，必要时平时查清。
6. 自相矛盾要核对对象、时间、条件、词义是否一致；**让步或反事实假设本身不自动构成矛盾**。课堂生产过剩例题的稳妥抓手，是核对“只是假象”与“常见现象”等具体断定。
7. 一段优先讲透一个主要缺口。跨到另一个得分点的回扣应短而清楚；不要将本来可以独立展开的多个漏洞揉成一段。
8. 谬误名称服务于分析，不代替分析。老师关于阅卷人、官方答案用词和得分的课堂判断，本笔记未另作官方核验，不作为得分保证或当年考试规则。

**课后最小练习**：拿一段没看过解析的论效材料，先画出“A→B”，再选择上表的一个分析动作，独立写一段；最后检查是否准确引用被质疑点、给出至少一个相关理由、没有把可能性说成必然性。
