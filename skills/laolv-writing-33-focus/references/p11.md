## ③ 阅读笔记

**核心论点。** XXY与普通双X最重要的区别，不在于多了一个字母，而在于**结果Y已经由材料确定**。文章须解释两个行为如何实现、影响或妨碍同一个结果，不能任意换成自己熟悉的“个人成长”“企业发展”等宽泛好处。

**课堂的论证结构。**

| 态度 | 主体结构 | 每段必须回答的问题 |
|---|---|---|
| 并重推Y | X₁有助于Y → X₂有助于Y → 单顾其一难以充分实现Y → 协同落实两者 | 两个X各通过什么机制作用于同一个Y？ |
| 偏重推Y | 主项X₁作用路径① → 主项X₁作用路径② → 忽视X₂的不足／X₂的补充作用 → 主次结合实现Y | 为什么X₁应居主位，X₂又补足哪一环？ |
| 取舍推Y | 所选X₁的优势① → 优势② → X₂对实现Y的局限 → 落实X₁ | 在材料条件下，哪一个方案更有利于达到Y，比较依据是什么？ |

展开时可以借用第9篇的**元素拆解法**，写成“X→F（中间作用）→Y”。XXY材料则要检验两条路径是否都回到相同Y，而不是把X₁、X₂、Y各写成互不相干的一段。

**例一的核心链条：两种教育→企业中坚人才。** 课堂以2021材料说明：道德教育通过责任意识、公共意识等塑造人才品格；科学教育通过观察、推断和判断能力提高人才专业素养。材料已经提供这些中间环节，学习重点是把它们解释成论证，而非另找一串名人故事。随后讨论只重德育或只重科学训练的不足，提出制度文化引导与培训实践并行。对象必须持续对应材料中的实业人才；这是本课采取的具体解读范围。

**例二的核心链条：冒尖／拔尖→管理人才选拔。** 课堂把“冒尖”理解为通过奋斗和实绩获得认可，把“拔尖”理解为通过提拔成为尖子；由“拔尖多、冒尖少”读出应更加重视冒尖的倾向。偏重写法允许拔尖补充组织发现、培养人才的功能；取舍写法比较两者对公平、动力等方面的影响。两种写法的区别集中在第三段如何评价次项、建议段最终落实什么。

**可套用表达（整理改写，非老师逐字原话）。**

- 中心判断：“实现Y，既需要X₁，也需要X₂。”
- 机制句：“X₁能够通过改善F₁，为Y创造条件；X₂则通过补足F₂，使这一目标获得进一步保障。”
- 并重辩证句：“只重视X₁而忽略X₂，可能出现A；只重视X₂而忽略X₁，又可能面临B，因此两者需协同。”
- 偏重句：“就材料指出的C问题而言，应把X₁放在更突出的位置，同时保留X₂在F方面的补充作用。”
- 建议句：“围绕Y，一方面通过M落实X₁，另一方面通过N完善X₂，使两条作用路径能够衔接。”
- 比较句：“评价X₁与X₂，不宜停留于各自的抽象优劣，而应考察它们在C条件下对Y的实际影响。”

**重点考点。**

1. **Y的锁定。** 标题可以压缩，但主张、分论点、机制和结尾应持续服务同一结果。
2. **S与O的辨别。** “谁采取行动”与“谁受影响”不必相同；“培养企业人才”中的人才既是对象，也包含在结果表述中，不要为了凑四个变量重复分析。
3. **材料内部可直接使用的机制。** 解释性括号、关键词和结果描述往往能提供F，优先利用这些内容再扩展。
4. **主次由材料支持。** 不能把所有XXY题都套成两者各半，更不能先背取舍模板再找理由否定一个X。
5. **主体段之间的联系。** 并重不是简单并列赞美，而是说明两种作用为什么共同服务Y；偏重和取舍也要有比较依据。

**易错注意点（包含整理者的写作提醒）。** “教育好处很多”不等于证明两种教育能够培养本题所说的人才；“冒尖有助于社会发展”也过于宽泛，需要回到管理人才如何被发现、选拔和培养。课堂允许“反对拔尖”的取舍立场，但训练时不要把组织提拔直接等同于关系用人；如要批评，应明确针对主观标准、关系干预等具体机制，并解释为什么这些问题在所设情境下可能发生。把材料描述补成“太多／太少”属于课堂的倾向判断，应有语境支撑，不能机械给任何数量词添加价值判断。课堂用于鼓励的“论证不必担心”等口语不能当作评分规则，正式写作仍需完整解释论点。

**60秒闭卷自测（学习建议）。** 写出X₁、X₂、Y，并各画一条“X→F→Y”的箭头。随后遮住标题，检查每条分论点是否仍能看出本题的Y；如果任何一段换成别的题目也完全适用，就补上本题特有的机制、对象或条件。
