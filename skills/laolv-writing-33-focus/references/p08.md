### ③ 阅读笔记

**核心论点。** 单X型已经给出主要行为或主题，无X型需要依据材料提炼主题；两者都未锁定一个必须论证的具体结果。先把 X 和态度确定，再选择恰当 S，标题保持简明；正文负责提出具体好处、说明现实障碍并给出对应措施。

**一个关键分界：有“结果字样”，不等于锁定 Y。** “发散性思维使人的言行与众不同”，没有限定不同体现在哪个方面，课堂按开放 Y 处理；可从解决问题、形成新方案等方向展开。“鸟类会飞”的结果也不能原样套给人或企业，迁移后要自行选择与优化有关的实际结果。但如果另一道材料明确要求证明 X 如何实现某个具体 Y，就应按第9篇的 XY 型处理，不能沿用此处的自由选结果方式。

**论证结构。** 两种结构均围绕同一个 X，分别如下。表中仅列主体段，前面还有引材料、提出论点的开头，后面还有回扣材料、重申主张的结尾。

| 段落功能 | 有好处式 | 好坏对比式 |
|---|---|---|
| 论证段1 | X → 具体好处Y₁ | 采取 X → 正面结果 |
| 论证段2 | X → 不同好处Y₂ | 缺乏／不采取 X → 负面结果 |
| 辩证段 | 现实中实行 X 存在哪些问题、困难或风险 | 同左，提醒正反比较之外还有实施条件 |
| 建议段 | 针对前述原因给出措施，使 X 得以落实 | 同左，不另起一个无关议题 |

课堂建议主体段大致按 **8、8、6、8行**安排，并在约40:11明确说可上下浮动。应理解成避免头重脚轻的篇幅提示，**不是官方规定，也不是必须凑到固定行数**。同样，课堂关于范文字数和格子数量的说法不作为本稿的官方字数核验结论。

| 课堂材料 | 核心立意 | 结构与展开要点 |
|---|---|---|
| 2023管综：领导与艺术相似 | 管理者应培养领导艺术。 | 个人影响力、团队凝聚力是两个不同作用方向；再指出命令式管理、把艺术误解为讨好等问题，用能力训练与组织保障回应。 |
| 2024管综：发散性思维 | 应培养发散性思维。 | 正面写解决问题的能力，反面写思维僵化对决策的影响；再分析经验惯性、风险顾虑、评价压力，并提供主动练习、激励与容错条件。 |
| 2022管综：鸟类不断优化身体结构 | 以企业为例，经营应不断优化。 | 总句的“优化”统摄后面的增强、改进、舍弃；好处可写管理效率、资源利用率；障碍与资源成本等实际条件相连。 |
| 2021经综：食蚁兽不毁尽蚁穴 | 以社会或企业为例，应坚持可持续发展。 | 从不过度消耗资源、保留恢复条件提炼主题；社会示例论证长期进步与降低系统风险，再回应短期利益诱因。此例是396迁移训练，不是199管综真题。 |

**可套用表达（以下均为整理改写，不是老师逐字原话）。**

- 标题：“〔S〕应当〔X〕。”如果材料没有限定主体且行为具有普适性，也可写“应当〔X〕”。
- 开头：“材料呈现了〔关键行为及关系〕。这启示我们，〔中心主张〕。”引材料宜概括，不必复制整段题干。
- 正面段：“〔X〕有助于〔具体结果〕。因为这一做法能够〔机制一〕，并通过〔机制二〕改善〔对象状态〕。”
- 反面段：“缺乏〔X〕，容易使〔主体〕陷入〔具体问题〕，进而影响〔结果〕。”正反论证仍须给理由，不能只把上一段加一个“不”字。
- 辩证与建议：“现实中，〔X〕的落实仍受〔原因A、B〕制约。因此，应通过〔措施A〕回应〔原因A〕，并以〔措施B〕补足〔原因B〕。”
- 结尾：“由材料可见，〔回扣关键关系〕。坚持〔X〕，才能更好地〔与正文一致的目标〕。”若“才能”表达的必要关系并未论证清楚，可改为“有助于”。

**重点考点与易错注意点。**

1. **单X材料优先保留原有主题词。** “领导艺术”已有明确指向，不宜为了套熟悉模板随意换成“创新”“沟通”或其他范围不同的概念；无X材料才需要进一步提炼主题。
2. **先认材料结构，再抓关键词。** 鸟类例的后半段是对“不断优化”的说明，仅抓“舍弃”会把局部做法当成全文中心。
3. **标题越具体，正文义务越多。** 题目未锁定 Y 时，自行写成“X助力企业发展”，会要求各段都解释企业发展，不能再以个人成长作独立落点。“简明标题”是降低无必要限制，不是取消题目本来给出的限制。
4. **主体不要无依据缩小或扩大。** “发散性思维”材料中的人未限定为管理者，直接保持一般个人主体更稳妥。课堂也讨论了管理类考试语境下的解释空间，但不宜将其写成普遍适用的评分定论。
5. **辩证不等于否定总论点。** 不必为了显得全面强造 X 的坏处；可以写现实中做不到、做不好 X 的原因，建议段再逐项回应。
6. **两条好处要真正不同。** “提高效率”和“工作更高效”是重复；应换成不同机制、对象或结果，并写清 X 如何促成它。
7. **无X不是随意联想。** 食蚁兽示例的“可持续发展”来自行为与资源再生的连续关系，不是凭动物故事套一个熟悉口号；也不能照搬动物主体写全文。
8. **本篇以审题、标题、提纲为学习目标。** 课堂多次说明段内展开另讲。未熟练前不必强背所有范文修辞，更不应把优美句子当成核心论证。

**60秒闭卷自测（学习建议）。** 依次回答：①“与众不同”为何不必视为锁定Y？②“鸟类不断优化”为什么不宜只写取舍？③有好处式的四个主体段各干什么？答案要点：结果开放；总句统摄细节；两条不同好处—实施障碍—对应建议。然后任选一则材料，只写标题和四句提纲，检查每句是否仍围绕同一 X。
