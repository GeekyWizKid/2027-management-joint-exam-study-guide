## ③ 阅读笔记

**核心论点。** 双X作文的核心是回答“两件事该怎样处理”。先确定X₁、X₂确实是并列核心词，再依据材料给出并重、偏重或取舍的判断，结构随判断变化。双X材料的Y可以未给出，也可以虽提及结果但仍具有开放性；若共同Y被锁定，就要转入第11篇的XXY分析。

**课堂的论证结构。** 标题先表达态度；开头概括材料并提出中心判断；主体安排如下；结尾回扣相同的两个X。

| 态度 | 主体四个功能段 | 成立条件 |
|---|---|---|
| 并重 | X₁的价值 → X₂的价值 → 只顾其一的局限 → 同时落实两者 | 两者都重要，并且材料允许兼顾。 |
| 偏重 | 主项X₁的价值① → 主项X₁的价值② → 忽略X₂的问题，或X₂的补充价值 → 以X₁为主、兼顾X₂ | 两者都有意义，但材料体现主次。 |
| 取舍 | 所选X₁的优势① → 优势② → 另一选项X₂在本情境中的不足 → 落实X₁并处理风险 | 存在资源限制、逻辑冲突或需要明确比较的决策。 |

课堂还补充了**关系型**写法：X₁→X₂、X₂→X₁，分别说明相互影响。它要求两条作用机制都站得住，不能只写“二者相辅相成”。它也不是所有双X作文都必须采用的结构。

**三则课堂材料的作用。** “为富与为仁”用于示范并重；“多样性与一致性”用于示范偏重，也讨论了并重的可行表达；“扩大生产与研发新品”用于示范受资金限制的取舍。课堂推荐研发新品，是该示例的一种论证选择，不等于题目只有这一立场可写。

**可套用表达（整理改写，非老师逐字原话）。**

- 并重标题／中心句：“既要重视X₁，也要落实X₂。”
- 偏重标题／中心句：“以X₁为重点，同时发挥X₂的补充作用。”
- 取舍中心句：“在C条件下，相比X₂，优先实施X₁更有利于解决当前问题。”
- 辩证衔接：“强调X₁的价值，并不意味着可以忽视X₂；缺少后者，前者可能面临……的限制。”
- 取舍比较：“X₂能够带来A，但在本题的C条件下，还存在B问题；综合比较，应优先选择X₁。”
- 建议收束：“应通过措施M落实X₁，并以措施N约束风险／兼顾X₂，使上述判断落到行动上。”

使用时必须把X、C、A、B等替换为材料中的具体行为、条件和机制；不能只换主题词而保留无关论证。

**重点考点。**

1. **并列关系的识别。** 两个词若是上下位概念、手段与目的，不能仅因数量为二就判作双X。
2. **态度与结构的一致。** 标题写“兼顾”，主体就不能把次项全盘否定；标题作取舍，正文就必须交代为何不选另一项。
3. **主题与手段的区别。** 2016示例中的教育可进入建议段，不能据此忽略多样性与一致性的核心关系。
4. **条件意识。** 2017示例必须处理“有限资金”，不能未经论证就说两项一起做。
5. **概念范围与主体。** “研发新品”比“创新”具体；材料问某家企业的选择，文章就要持续回应这一企业决策。

**易错注意点（包含整理者的写作提醒）。** 不要把“偏重”写成“只要主项”；不要把取舍理解为可以捏造另一选项的缺点。本题比较应当承认材料已给出的收益和风险，再解释为什么在这些条件下仍作出该选择。课堂口语中的“捧一个、踩一个”适合理解结构，成文时应改成有条件、有依据的优劣比较。2016例按“个人／社会”展开的是社会多样性对不同对象的作用，不能由此把全文行动主体随意换成个人。课程中的概括性商业论断不宜脱离条件当作事实定律引用。

**60秒闭卷自测（学习建议）。** 读一则双X材料，只写四行：①两个X及其是否并列；②材料有没有锁定Y；③决定并重、偏重或取舍的原文条件；④四个主体段各做什么。如果第三行写不出来，先返回材料，暂不套结构。
