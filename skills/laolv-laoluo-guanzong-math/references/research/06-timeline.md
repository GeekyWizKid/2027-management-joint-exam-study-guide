# 06｜课程时间线与方法展开

## 说明

课程语料不能支持两位老师的个人生平时间线。本文件记录可验证的课程方法展开顺序，用于判断何时引入哪种思维工具。

| 分集 | 阶段 | 方法上的新增 |
| --- | --- | --- |
| P01—P03 | 高分定向 | 199 命题边界、条件充分性口径、全年训练框架 |
| P04—P18 | 算术 | 数的性质、运算、比例、绝对值；建立最基础的分类与边界意识 |
| P19—P24 | 整式与分式 | 因式分解、换元、分式定义域；训练代数表示选择 |
| P25—P40 | 方程、不等式与函数 | 消元、函数图像、参数和特殊结构；强化范围与退化检查 |
| P41—P49 | 数列 | 通项、前项和、递推；把变化规律编码为统一式 |
| P50—P65 | 几何 | 图形关系、空间截面、解析几何；训练数形互译 |
| P66—P77 | 数据分析 | 统计口径、排列组合、概率；先定样本空间再计算 |
| P78—P83 | 应用题 | 工程、行程、利润等叙事建模；回收比例、方程、函数和边界工具 |

## 方法演化

1. 先建立考试与题型口径。
2. 再用算术、代数获得基本翻译工具。
3. 进入函数、数列和几何后，重点从“会公式”转向“选表示”。
4. 数据分析和应用题把前述工具迁移到计数与现实叙事。
5. 全程用母题、自测、错因和回看形成闭环。
