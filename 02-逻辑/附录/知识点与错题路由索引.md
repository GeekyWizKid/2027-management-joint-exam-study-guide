# 逻辑知识点与回看路由索引

> 两套课使用的章节组织不同；本索引按考试动作合并，保留各自分集编号，便于从错题直接回看。

| 能力块 | 知识点/题型 | 核心动作 | 回看分集 |
| --- | --- | --- | --- |
| 形式语言 | 命题符号、联言/选言、取非与真假 | 先拆原子命题，再确定联结词和作用域 | 形式-P04—P08 |
| 四项硬规则 | 外层取非、OR/箭头转换、逆否、只能顺推 | 任何选项都回到等价式或反例验证 | 形式-P09—P12 |
| 前真后假与OR | 假言唯一假情形、相容/不相容选言、文字转译 | 先写A且非B；OR未关闭时保留分支 | 形式-P13—P20 |
| 量词与模态 | 全称/特称、必然/可能及‘都’字变法 | 否定时同时改变量词与谓词 | 形式-P21—P24 |
| 事实代入 | 以事实真触发逻辑真并判断其他命题真假 | 前件真顺推、后件假逆否；未知不等于假 | 形式-P25—P32 |
| 判断逻辑真假 | 简单套路、复杂套路与选项语言改写 | 用逆否、OR 与唯一假情形判断 | 形式-P33—P39 |
| 分析五套路 | 矛盾定真、名额、一一对应、条件矛盾、两难 | 优先数量和重复元素，推出事实后回填 | 形式-P40—P43 |
| 真假话与陷阱 | 矛盾/同真同假/代入计数；三类高频混淆 | 先锁关系组和真假总数，再做最少假设 | 形式-P44—P49 |
| 集合与直言 | 文氏图、三段论、直言命题 | 先画全称边界，再放存在点并造反例 | 形式-P50—P55 |
| 分析推理 | 排队列、分组、多对多表格、数独与相邻 | 画位置/分组表，所有合法分支取交集 | 形式-P56—P63；论证-P62—P72 |
| 假设 | 补全逻辑型、引入前提型与过强假设 | 搭桥后做否定检验，区分足够与必要 | 论证-P04—P14 |
| 支持 | 前真后真、前假后假及常见陷阱 | 明确支持的是结论、论据还是连接 | 论证-P15—P20 |
| 建立联系型支持 | 论据与结论发生对象/概念切换 | 圈出两端对象，用选项补上桥梁关系 | 论证-P21—P24 |
| 削弱 | 因果、求异、幸存者、比例、稀释、基准与第三变量 | 先找论证缺口，再比较针对性与力度 | 论证-P25—P50 |
| 解释 | 解释矛盾与解释现象 | 同时保留两端事实，用同一机制连接 | 论证-P51—P53 |
| 评价 | 评价问题与评价论证 | 相反答案应把结论推向相反方向 | 论证-P54—P56 |
| 对话与结论 | 两人争论焦点、结论推出 | 抓共同话题和分歧点；结论不超出题干 | 论证-P57—P61 |
